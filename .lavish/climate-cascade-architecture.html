ADR-0001 Flood MVP Local-first

Code owns control

Agents own bounded judgment. Python owns state, data access, geospatial analysis, arithmetic, retries, approvals, and exports.

Only two model roles exist in the final design: a response supervisor drafts actions, and an independent evidence and safety supervisor challenges them.

Final topology

One durable workflow, two bounded agents

flowchart TD U["Emergency analyst"] --> UI["React dashboard"] UI -->|"HTTP and SSE"| API["FastAPI control API"] API --> DB["SQLite and event stream"] DB --> W["Durable Python worker"] W --> O["Deterministic state machine"] O --> RS["Response supervisor"] O --> VS["Evidence and safety supervisor"] O --> T["Typed tool registry"] T --> S["Source adapters"] T --> G["Geospatial and access engines"] T --> L["Life-safety calculator"] S --> A["Content-addressed artifacts"] G --> A O --> H["Human review checkpoint"] H --> X["Reviewed exports and trajectory"]

Agent 1

Response supervisor

Reads verified evidence and compact impact results, queries allowlisted read-only tools, and drafts typed actions.

No network No database No approval

Agent 2

Evidence and safety supervisor

Independently checks claims, locations, population, estimates, ownership, dependencies, and prohibited instructions.

Pass Revise Reject

Authority

Qualified human

Approves, edits, requests evidence, or rejects. No model or tool can move an action to approved.

Rationale required Versioned decision

Contracts

Everything crosses a typed boundary

Pydantic: API, agents, tools, events, exports
Versioning: schemas, prompts, policies, tools, configs
Idempotency: run, stage, tool, version, input hash
Evidence: immutable IDs and content hashes

Memory

Explicit, scoped, reproducible

  • SQLite run, action, review, tool, and trajectory memory
  • Immutable evidence snapshots in a content-addressed store
  • Versioned policy and prompt files
  • No vector database until a measured retrieval failure justifies it
  • No automatic conversion of reviewer feedback into policy

Downstream boundary

Reviewed exports, not execution

The MVP produces Markdown, PDF, JSON, CSV, GeoJSON, and JSONL. It does not connect to dispatch, public alerts, hospitals, messaging, infrastructure control, or incident-command systems.
